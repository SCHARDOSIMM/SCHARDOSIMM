## Primeiro projeto publicado

### [MS Estruturas](https://github.com/SCHARDOSIMM/ms-estruturas)

Aplicação desktop em Python para modelagem e análise linear de estruturas de barras, com interface em português e inglês, visualização de resultados e exportação de relatórios.

- **Versão publicada:** 1.0.3, com instalador para Windows e guias em português e inglês.
- **Tecnologias:** Python, PyQt5, ReportLab, PyInstaller e Inno Setup.
- **Conhecimentos aplicados:** análise estrutural, interface gráfica, testes automatizados, documentação e distribuição de software.

[Ver código-fonte](https://github.com/SCHARDOSIMM/ms-estruturas) · [Baixar programa e guias](https://github.com/SCHARDOSIMM/ms-estruturas/releases/tag/v1.0.3)

*A análise é linear de primeira ordem e não realiza dimensionamento normativo. Consulte as hipóteses e limitações na documentação do projeto.*
